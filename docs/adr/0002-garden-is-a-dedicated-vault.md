# The Garden is a dedicated Obsidian vault, published by default

Garden Notes live in a folder in this repo that is opened as its own Obsidian vault. It is separate from the author's personal vault. Anything in it is published once merged unless it is marked as a Draft. We rejected two alternatives: publishing selected notes from the personal vault, and making the repo the main vault with private notes excluded. Keeping private writing out of the repo entirely means nothing can leak through a missed flag, and every wiki-link points at a Note that exists in the Garden.
